Neon Overtake

A vertical arcade driving game for Windows, built using Python. Overtake traffic, build a high score, and stay in control as the game speeds up.

Download Windows Installer ↓

Project Overview

Neon Overtake is a lightweight, 2D arcade game inspired by highway driving. Unlike horizontal side-scrollers, the game follows a vertical highway as you avoid approaching vehicles.

Cars appear in randomized positions, difficulty increases with each overtake, and your personal-best score encourages replayability. The game includes a start menu, settings, and a game-over screen.
