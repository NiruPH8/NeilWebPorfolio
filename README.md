# Neil Bryan C. Paguigan — Corporate Portfolio

A professional, responsive website intended for sharing with employers and recruiters.

## How to run
Open `index.html` directly in your browser, or use VS Code Live Server.
To publish, upload all files **with the assets directory** to a GitHub Pages repository.
No dependencies or installation are required.

## Files
- `index.html`: Homepage — Home, About, Skills, Experience, Work, Education, Contact
- `video-editing.html`: Two YouTube video samples embedded with fallback links
- `neon-overtake.html`: Game details, screenshots and installer
- `style.css`: All responsive design
- `script.js`: Mobile navigation, navbar scroll treatment, active links
- `assets/`: Local hero landscape, profile picture, screenshots, favicon

## Design and browser support
- Static HTML/CSS/JS: no frameworks, CDN, or build step.
- Designed for Chrome, Edge, Firefox, and Safari (desktop/mobile).
- Responsive mobile navigation, flexible layout, no draggable windows.
- Includes keyboard-visible focus and reduced-motion support.
- YouTube embeds load from YouTube and may be blocked by privacy settings; direct links included.
- Form submission is not used; contact is via email link.
